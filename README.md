# Portfólio - Luiz Gustavo Monico

Um portfólio moderno e responsivo desenvolvido com HTML, CSS e JavaScript, apresentando um design avançado com tema escuro.

## 🚀 Características

- **Design Moderno**: Interface elegante com tema escuro e gradientes vibrantes
- **Totalmente Responsivo**: Adaptado para desktop, tablet e mobile
- **Animações Avançadas**: Efeitos de scroll, transições suaves e micro-interações
- **Performance Otimizada**: Código limpo e otimizado para carregamento rápido
- **Interatividade Rica**: JavaScript avançado com múltiplas funcionalidades

## 🎨 Seções

1. **Hero Section**: Apresentação principal com animações flutuantes
2. **Sobre Mim**: Informações pessoais e estatísticas animadas
3. **Experiência**: Timeline profissional interativa
4. **Projetos**: Cards de projetos com hover effects e overlay
5. **Habilidades**: Grid de tecnologias organizadas por categoria
6. **Contato**: Formulário funcional com validação

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica moderna
- **CSS3**: 
  - Flexbox e Grid Layout
  - Animações e transições CSS
  - Variáveis CSS customizadas
  - Media queries para responsividade
- **JavaScript ES6+**:
  - Intersection Observer API
  - Event listeners avançados
  - Animações programáticas
  - Validação de formulários

## 📱 Funcionalidades JavaScript

- **Navegação Suave**: Scroll suave entre seções
- **Menu Mobile**: Hamburger menu responsivo
- **Animações de Scroll**: Elementos aparecem conforme o scroll
- **Efeito Parallax**: Movimento sutil no hero section
- **Contador Animado**: Números das estatísticas animados
- **Validação de Formulário**: Validação em tempo real
- **Sistema de Notificações**: Feedback visual para ações
- **Cursor Personalizado**: Efeito visual em desktop
- **Preloader**: Tela de carregamento animada

## 🎯 Recursos de Design

- **Paleta de Cores**:
  - Primary: #00d4ff (Cyan vibrante)
  - Secondary: #ff6b6b (Coral)
  - Accent: #4ecdc4 (Turquesa)

- **Tipografia**: Inter (Google Fonts)
- **Ícones**: Font Awesome 6.0
- **Gradientes**: Múltiplos gradientes para elementos visuais
- **Sombras**: Sistema de sombras em 3 níveis

## 🚀 Como Usar

1. **Visualização Local**:
   - Abra o arquivo `index.html` em qualquer navegador moderno
   - Todas as dependências são carregadas via CDN

2. **Personalização**:
   - Edite as informações pessoais no `index.html`
   - Ajuste cores e estilos no `styles.css`
   - Modifique comportamentos no `script.js`

3. **Hospedagem**:
   - Faça upload dos arquivos para qualquer servidor web
   - Compatível com GitHub Pages, Netlify, Vercel, etc.

## 🔧 Customização

### Alterando Cores
Edite as variáveis CSS no início do arquivo `styles.css`:

```css
:root {
    --primary-color: #00d4ff;
    --secondary-color: #ff6b6b;
    --accent-color: #4ecdc4;
    /* ... outras variáveis */
}
```

### Adicionando Projetos
No arquivo `index.html`, adicione novos cards na seção de projetos:

```html
<div class="project-card">
    <div class="project-image">
        <img src="caminho-da-imagem.jpg" alt="Nome do Projeto">
        <!-- ... resto da estrutura -->
    </div>
</div>
```

### Modificando Animações
Ajuste as animações no arquivo `script.js` ou adicione novas no `styles.css`.
